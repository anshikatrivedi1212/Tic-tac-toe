# Tic-tac-toe Game
A simple console-based Tic-Tac-Toe game developed in Python.

## Features

- Two Players mode
- Player vs Computer mode
- 3×3 game board
- Position validation
- Winner detection
- Draw detection
- Play again option

## Technologies Used

- Python
- Jupyter Notebook

## Python Concepts Used

- Variables
- Lists
- Tuples
- Loops
- If-else statements
- User input
- Type conversion
- Indexing

## How to Run

1. Download or clone this repository.
2. Open Tic_Tac_Toe.ipynb in Jupyter Notebook.
3. Run the code.
4. Select a game mode and start playing.
